# ML Service (Flask)

Recommendations and demand forecasting for AI Canteen Connect. Runs on port 8000.

```bash
cd ml-service
pip install -r requirements.txt
python app.py
```

## Endpoints

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/health` | Status and the demand model's test metrics |
| POST | `/recommend` | Body `{"history": [item_ids], "top_k": 5}`. Hybrid recommendations (collaborative item-item + TF-IDF content). No history returns popular items. |
| GET | `/forecast?category=Meals&day_of_week=2&hour=13` | XGBoost prediction of items ordered in that hour for a category |

## Data

The service reads `data/items.csv` and `data/orders.csv`.

- If they are missing, **synthetic demo data** is generated by `data/generate_sample_data.py` so the service can run. Metrics from synthetic data only show that the pipeline works.
- To use real data, export your orders to `data/orders.csv` (`user_id, item_id, quantity, timestamp`) and your menu to `data/items.csv` (`item_id, name, category, description`), delete `models/demand_model.pkl`, and restart. The metrics shown at `/health` will then come from your real data.

## How it works

- `recommendation.py`: score = 0.6 x collaborative similarity + 0.4 x content similarity, excluding items already ordered. `hit_rate_at_k()` evaluates it with a leave-one-out test.
- `forecasting.py`: XGBoost regressor on hour, day of week, weekend flag and category. Accuracy is reported as 1 - WAPE.
